# Active Directory Home Lab

## Description
Hands-on Active Directory IAM lab using VirtualBox, Windows Server and Windows 10 to practise user and group management, authentication, Group Policy, and access control.
<br />


## Environments Used 

- <b>Windows Server 2019 and Windows 10</b>
